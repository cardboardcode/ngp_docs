## **What Is `next_gen_prototype`?**

A preliminary reference implementation of **Open-RMF Next Generation** which is built around 4 core design goals:

- **Modularity**: Capabilities like dispatching and traffic planning are provided by interchangeable modules
- **Standardization**: First-class support and bridges for VDA5050, MassRobotics AMR Interop, and Nav2.
- **Robot Versatility**: Native support for both Automated Guided Vehicles (AGVs) and Autonomous Mobile Robots (AMRs)
- **Commercial Friendly**: Providing open-source reference implementations for all major capabilities
